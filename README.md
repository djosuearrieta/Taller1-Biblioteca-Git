# Library Management System

*Workshop 1 - Programming III - UPC*

## Author
Daniel Josué Arrieta Fontalvo - 1065615550

## Description
Console application in Java to manage clients, books, and loans of a library. In-memory storage (ArrayList).

## How to run
1. Open the project in NetBeans
2. Build with Maven
3. Run Main.java

## Features
- Client CRUD
- Book CRUD
- Loan registration and returns
